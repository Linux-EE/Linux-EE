# Linux-EE Changelog

## Linux-EE Sky 2026.0 - 2026-11-10

* System updates have been applied to the downloaded copy of KDE Neon.
* The “Bleachbit” software has been added so that users can clean up unnecessary files from their copy of Linux-EE.
* Since we believe it places greater emphasis on privacy and security, we have selected Zen Browser as the default browser; however, you can change this later if you wish.
* The latest version of LibreOffice has been installed so that users can easily work with relevant documents.
* Wine/Bottles has been installed by default to allow Windows programs and games to run.
