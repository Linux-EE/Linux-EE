## What is Linux-EE, in a nutshell?

Linux-EE is a Linux distribution designed to provide a smooth and comfortable experience for everyone meaning it’s ready to use right out of the box.

> Key points:

* Linux-EE is not a Linux distribution developed from scratch; it does not have its own DE (Desktop Environment) or package manager.
* Linux-EE is based on KDE Neon, an Ubuntu-based distribution.
* There is no guarantee that everything will work flawlessly.

## Why the name Linux-EE?

Because I wanted the name to accurately reflect the distribution I created Linux-EE aims to provide a comfortable and convenient experience for everyone, and I chose this name, which stands for
Linux-EE (Everything Edition), to accurately represent my Linux distribution.

## Why was Linux-EE developed?

The primary goal behind creating Linux-EE is to ensure that users transitioning from Windows to Linux can navigate the learning curve smoothly. That’s why this distribution comes pre-installed with Wine and Bottles, allowing users to
easily run “.exe” files. (It’s worth noting that not every “.exe” file will work.)

> So, what tool was used to build it?

* [Cubic](https://github.com/PJ-Singh-001/Cubic)

## Can I view the source code for Linux-EE?

I'm sorry, but no. The reason is that Linux-EE does not include any proprietary tools developed by the “Linux-EE” team. This distribution is based on KDE Neon, but don't worry we'll share the other details in the “CHANGELOG.md” file.
